## Código

É bem fácil mostrar código em arquivos markdown.

Crases podem ser usadas para destacar algumas palavras.

Além disso, qualquer bloco indentado é considerado um bloco de código. Se `enable_highlight` estiver definido como `true`, o destaque de sintaxe será incluído (para o analisador embutido — o analisador do GitHub faz isso automaticamente).

```html
<script>
document.location = 'http://lmgtfy.com/?q=markdown+cheat+sheet';
</script>
```

## Matemática

Fórmulas matemáticas podem ser exibidas no navegador usando MathJax ou Katex. O recurso pode ser ativado configurando corretamente os campos de configuração `"js"`, `"css"` e `"markdown_extensions"`. Isso permite a inclusão de matemática inline:

\(\frac{\pi}{2}\) \(\pi\).

Alternativamente, a matemática pode ser escrita em sua própria linha:

\[
\int_0^1 f(t) \mathrm{d}t
\]

\[
\sum_j \gamma_j^2/d_j
\]

## Analisadores e Extensões

O Markdown Preview vem com o **Python-Markdown** pré-carregado.

### *Python-Markdown*

O Analisador Python-Markdown oferece suporte a várias extensões.

#### Extensões Extras

- `abbr` -- Abreviações
- `attr_list` -- Listas de Atributos
- `def_list` -- Listas de Definição
- `fenced_code` -- Blocos de Código Delimitados
- `footnotes` -- Notas de Rodapé
- `tables` -- Tabelas
- `smart_strong` -- Negrito Inteligente

Você pode ativá-las todas de uma vez usando a palavra-chave `extra`.

```yaml
extensions: ['extra']
```

Se você quiser todos os extras mais a extensão `toc`, suas configurações ficariam assim:

```yaml
{
    ...
    parser: 'markdown',
    extensions: ['extra', 'toc'],
    ...
}
```

#### Outras Extensões

Também existem algumas extensões que não estão incluídas no Markdown Extra, mas vêm na biblioteca padrão do Python-Markdown.

- `code-hilite` -- Destaque de Código
- `header-id` -- ID de Cabeçalho
- `meta_data` -- Metadados
- `nl2br` -- Quebra de Linha Automática
- `sane_lists` -- Listas Sensatas
- `smarty` -- Smarty
- `toc` -- Sumário
- `wikilinks` -- WikiLinks

#### Extensões de Terceiros

O *Python-Markdown* foi projetado para ser estendido.

Algumas das extensões incluídas são:

- `delete` -- suporte a tachado no estilo GitHub via ~~palavra~~
- `githubemoji` -- suporte a emojis do GitHub
- `tasklist` -- listas de tarefas no estilo GitHub
- `magiclink` -- conversão automática de links http|ftp no estilo GitHub
- `headeranchor` -- links de âncora para cabeçalhos no estilo GitHub
- `github` -- adiciona as extensões acima de uma só vez
- `b64` -- converte e embute imagens locais em base64. Configurado adicionando `b64(base_path=${BASE_PATH})`

Existem também várias outras disponíveis.

Basta fazer um fork deste repositório e adicionar suas extensões dentro da pasta:

`.../Packages/Markdown Preview/markdown/extensions/`

Confira a lista de Extensões de Terceiros.

#### Extensões Padrão

As extensões padrão são:

- `footnotes` -- Notas de Rodapé
- `toc` -- Sumário
- `fenced_code` -- Blocos de Código Delimitados
- `tables` -- Tabelas

Use a palavra-chave `default` para selecionar todas elas.

Se você quiser todos os padrões mais a extensão `definition_lists`, suas configurações ficariam assim:

```yaml
{
    ...
    parser: 'markdown',
    extensions: ['default', 'definition_lists'],
    ...
}
```
